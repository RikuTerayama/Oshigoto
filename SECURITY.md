# Security Policy

## Supported branch

Security fixes are applied to the `main` branch. Please reproduce issues against the latest deployed revision or the latest `main` commit before reporting them.

## Reporting a vulnerability

Use the [Oshigoto contact form](https://oshigoto.onrender.com/contact) and clearly mark the message as a security report. Do not open a public GitHub issue for a vulnerability, and do not include passwords, API keys, access tokens, private documents, or other secrets in a report.

Please include:

- the affected URL or component;
- the vulnerability type and expected impact;
- minimal reproduction steps;
- whether authentication or a specific browser is required;
- a safe proof of concept without real user data;
- suggested remediation, if known.

We will acknowledge actionable reports, investigate them, and coordinate remediation before public disclosure. Avoid destructive testing, privacy violations, service disruption, and access to data that is not your own.
