QRコードを作る

URL、テキスト、メール、電話番号、Wi-Fi接続情報をQRコードにして、PNGまたはSVGで保存できます。

入力内容と生成処理はブラウザ内に留まり、Oshigotoのサーバーへ送信されません。

{% include 'includes/affiliate_primary_rail.html' %}

使う順番

  1. QRの種類を選ぶURL、テキスト、メール、電話番号、Wi-Fiから選択します。
  2. 内容を入力するQRコードに入れるURLや文章などを入力します。
  3. サイズと設定を選ぶ誤り訂正、画像サイズ、余白を必要に応じて調整します。
  4. QRコードを生成して保存する生成後にPNGまたはSVGで保存します。

1. QRの種類を選ぶ

作成する内容に合う種類を選びます。

QRコードの種類

2. 内容を入力する

QRコードに格納する内容を入力します。

http:// または https:// のURLだけを使用できます。リンク先の安全性はこのツールでは確認しません。
日本語、英語、絵文字、改行を含められます。
数字、先頭の+、空白、ハイフン、丸括弧を入力できます。QRコードを作るだけで、発信はしません。
パスワードは表示、保存、送信しません。

Wi-Fi用QRコードには接続パスワードが含まれます。共有先と保存場所を確認してから使用してください。

0 / 1,000 bytes

3. サイズと誤り訂正を設定する

標準設定のままでも作成できます。読み取りやすさは端末や印刷状態でも変わります。

読み取りやすさを優先し、前景は黒、背景は白で固定しています。

ブラウザ内で完結

入力内容をアップロードせず、表示中のブラウザでQRコードを作成します。入力内容はCookieやブラウザストレージへ保存しません。

使用前に読み取り確認

読み取りやすさは、端末、印刷サイズ、色、汚れなどで変わります。重要な案内に使う前に、実際の端末で確認してください。
